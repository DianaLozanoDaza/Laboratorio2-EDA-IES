# 📊 Análisis Exploratorio de Datos — IES Colombia

## Descripción
EDA sobre las Instituciones de Educación Superior en Colombia, 
integrando dos fuentes de datos: una API pública del portal 
datos.gov.co y la base de datos SNIES del Ministerio de Educación.

## 🗂️ Fuentes de datos
- **API:** https://www.datos.gov.co/resource/g5uh-29gw.json
- **Excel:** SNIES — Personal Administrativo 2024

## 🛠️ Tecnologías utilizadas
- Python
- Pandas
- Matplotlib
- Scipy

## 🔍 Hallazgos principales
- 299 instituciones únicas analizadas
- Bogotá D.C. concentra el 35% de las IES del país
- El sector privado representa el 69% de las instituciones
- Bogotá, Antioquia y Valle del Cauca concentran la mayoría de IES
- Prueba Chi-cuadrado confirma distribución no uniforme (p = 0.0000)
